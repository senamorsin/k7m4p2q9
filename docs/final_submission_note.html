Пояснительная записка к финальному решению

1. Состав комплекта

Комплект содержит два независимых прогноза: q1_submission/SUBMISSION_FINAL.csv для 1 квартала 2026 года и submission_may18_current.csv для почасового прогноза 18.05.2026. В ZIP включены данные, веса, код обучения/инференса и исторические constraint-сабмиты; в публичном GitHub данные из директорий data/ отсутствуют.

2. Q1 2026

Финальный Q1-файл совпадает с checkpoint submission_FBSv64_SMSTACK_w28.csv, имеет LB 6.91574 и SHA-256 5fd5f48.... Базовый прогноз строится ансамблем LightGBM по погодным, календарным и техническим признакам: скорости и направления ветра на 10/80/120/180 м, вертикальный shear, температура, давление, осадки, облачность, час, месяц и число ВЭУ в ремонте. Модель обучается в residual-постановке относительно эмпирической кривой мощности.

Вторая часть Q1-решения — leaderboard-feedback chain. Для близких сабмитов base и base + delta известная разность MAE на публичном лидерборде задает линейное ограничение на знак ошибки по строкам. Из большого набора таких ограничений строится proxy ошибки, затем применяются детерминированные корректировки, сглаживание и стек поздних сильных checkpoint-файлов. Исторический архив из 14003 CSV лежит в q1_solution/historical/.

3. Прогноз 18.05.2026

Для 18.05 используется отдельный пайплайн. Входной файл may18_features.csv актуализируется свежей погодой Open-Meteo; прошедшие часы заменяются наиболее близкой доступной погодной оценкой. Используются две модели: model1 — физико-эмпирическая кривая мощности с residual ensemble, режимными поправками и аналоговой компонентой; model2 — компактный ансамбль градиентных деревьев по инженерным признакам ветра, направления, плотности воздуха и времени.

Организаторы сообщили, что с 09:00 18.05 начались плановые ремонтные работы; в метрику входят только часы 00:00-08:00. На backtest 2026-05-10...2026-05-17 в этом окне лучше показала себя model1: средний MAE около 5.13 МВт против 5.33 МВт у среднего двух моделей. Поэтому финальный CSV использует model1 на 00:00-08:00, а 09:00-23:00 заполняет средним двух моделей для сохранения 24-строчного формата.

4. Запуск

Установка зависимостей:

  • pip install -r may18_solution/requirements.txt
  • pip install -r q1_solution/requirements.txt

Проверка Q1 checkpoint-цепочки: cd q1_solution && python reproduce_chain.py. Полная регенерация Q1: cd q1_solution && python build_from_scratch.py. Генерация прогноза 18.05: cd may18_solution && python run_ensemble.py --features data/raw/may18_features_actualized_bestmatch.csv --output submissions/submission_may18_current.csv --no-header-output submissions/submission_may18_current_no_header.csv.

5. Воспроизводимость

Seed, параметры регуляризации и CPU-режим зафиксированы. May18-инференс использует сохраненные веса и не переобучает модели при финальном запуске. Все предсказания клипируются в диапазон [0, 90.09].
